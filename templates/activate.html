Paste your code

Use the activation dialog at startup, or open Settings → Account and choose “Change code”.

Check your plan

Settings → Account shows the plan, expiry, daily limit, and how much time is left today.

Moved to a new PC? A code allows the number of devices shown on your plan. Open Settings → Account on the old machine and choose “Remove this device” to free its slot, then activate the same code on the new machine. Do not buy a second plan just to switch machines.

Common activation errors

The app says the code was not found

Check for missing characters. The code is 12 characters in four groups, and the ML- prefix is optional. Copy it from the success page rather than retyping.

The code has reached its device limit

This plan is already active on all its allowed devices. Remove an old device in Settings → Account or contact support; do not create a second order.

The app cannot reach the activation server

Check your connection and the server URL in Settings → Account → Advanced. Activation requires internet the first time; an already-activated device can keep working offline within the app's grace policy.

I reached my daily limit

The current session stops and the app shows the reset time. Limits reset at 00:00 UTC. You can still change settings and prepare your next session.
