Got Questions?

Frequently Asked Questions

Do I need a dedicated GPU to run Moonlight Studio?

No! The desktop app, real-time DSP voice effects, and basic passthrough run comfortably on standard CPUs. For advanced deep learning avatar models (LivePortrait) and neural voice synthesis (Seed-VC), an NVIDIA CUDA GPU is recommended, or you can utilize cloud GPU minutes included in higher plans.

How does the daily studio allowance work?

Your daily studio allowance (e.g., 2, 4, or 8 hours) measures active live camera/voice transformation time. When your time runs out, the engine stops gracefully, and the limit resets every night at 00:00 UTC. The app itself remains fully open so you can configure profiles and test audio.

Can I use one code across multiple PCs?

Yes! Depending on your plan (e.g. Creator allows 2 devices, Studio allows 4), you can activate the same code on multiple computers. All active devices share the same pooled daily allowance, and you can easily deactivate an old PC from Settings to free up its slot.

Which payment methods are accepted?

We support secure hosted checkouts powered by Paystack and Flutterwave, accepting cards, bank transfers, and USSD. Your card credentials never touch Moonlight Studio servers.

How do I receive my activation code?

As soon as payment completes, your unique 12-character code is displayed on screen with a one-click copy button, and a full receipt copy is immediately dispatched to your email address via Resend.
